# Docs

This website is my personal portfolio, for showcasing my skills and 
qualifications.

While this is my personal portfolio, this is also somewhere I can
mess around with web dev and UI / UX as well as try out some ideas.

## Tech Stack

This website is built with pure HTML, CSS and Javascript.

## Project Structure

```
┌─ docs                 # contains all the documentation for the project
├─ src                  # contains all the content and resources for the website
├──── content           # contains the HTML for the section as well as any custom CSS & JS overrides
├──── resources         # website resources
├─────── flags          # custom svg country flags
├─────── icons          # custom svg icons
├─ index.css            # main CSS
├─ index.html           # main HTML file for GitHub Pages
├─ index.js             # main JS
└─ README.md
```
